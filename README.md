# Submodular Diversity Reranker & News Preprocessin

This project provides an end-to-end pipeline to preprocess media bias datasets and perform submodular optimization to rerank news articles, balancing keyword relevance with ideological diversity.

---

## 📌 Project Overview

Media consumption often suffers from filter bubbles and ideological bias. This repository contains scripts to:
1. **Preprocess raw AllSides-style news data** (`bias_clean.csv`) into a standardized JSON format.
2. **Re-rank candidate articles** using a **greedy submodular optimization algorithm** to maximize query relevance while penalizing over-representation of the same political stance in the top recommendations.

## 📊 Dataset Schema

### Input Format (`bias_clean.csv`)
The input CSV file must contain the following columns in exact order:

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `url` | String | Unique web link to the news article. |
| `topic` | String | Topic category (e.g., `general-news`, `coronavirus`, `defense-and-national-security`). |
| `date` | String | Publication date (e.g., `12/31/2020`). |
| `title` | String | Title or headline of the news article. |
| `site` | String | News outlet/publisher (e.g., `NPR`, `Fox News`, `The Guardian`). |
| `bias` | String | Text-based political bias label (`left`, `leaning-left`, `center`, `leaning-right`, `right`). |
| `page_text` | String | Full raw text body of the article. |

### Processed Schema (`mock_database.json`)
The preprocessed database maps and standardizes fields into numerical values used by the submodular reranker loop:

```json
[
  {
    "id": "https://www.example.com/article",
    "text": "Full body text of the article...",
    "topic": "coronavirus",
    "stance": -1.0
  }
]
```

#### Stance Numerical Mapping:
* **`left`** $\rightarrow -1.0$
* **`leaning-left`** $\rightarrow -0.5$
* **`center`** $\rightarrow 0.0$
* **`leaning-right`** $\rightarrow 0.5$
* **`right`** $\rightarrow 1.0$

## 🧮 Submodular Reranking Algorithm

The reranking engine uses a greedy algorithm based on a submodular objective function to pick $k$ articles:

$$f(S \cup \{i\}) - f(S) = \text{Relevance}(i, Q) - \lambda \cdot \text{Redundancy}(i, S)$$

Where:
* **Relevance:** Number of query keyword matches in article text $+ 1.0$ (base score).
* **Redundancy:** Frequency ratio of candidate article's stance within already selected articles $S$.
* **$\lambda$ (lambda_param):** Diversity penalty weight coefficient (default: `0.5`). High values heavily penalize repeated political stances in the output feed.

## ⚙️ Usage Instructions

### Step 1: Preprocess the Dataset

Run `data_preprocessing.py` to read `bias_clean.csv` and generate `mock_database.json`.

```bash
python data_preprocessing.py
```

### Step 2: Run the Reranking Engine

Execute `reranker_engine.py` to test submodular reranking on the mock database for query keywords.

```bash
python reranker_engine.py
```

#### Code Snippet Example:

```python
from reranker_engine import load_database, submodular_rerank

# Load preprocessed database
database = load_database("mock_database.json")

# Define query keywords and parameters
query = ["election"]
lambda_param = 0.6  # Weight for political diversity penalty
top_k = 5          # Number of items in returned feed

# Execute submodular reranker
diversified_feed = submodular_rerank(database, query, lambda_param=lambda_param, k=top_k)

# Print results
for i, article in enumerate(diversified_feed, 1):
    print(f"{i}. [Stance: {article['stance']}] Topic: {article['topic']} - ID: {article['id']}")
```
